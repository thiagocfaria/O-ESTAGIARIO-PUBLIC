# Contribua com problemas reais, não com dados de clientes

Este repositório recebe sugestões de rotinas, perguntas técnicas e correções da documentação pública. O código do produto não é distribuído aqui; não há instrução pública para instalar ou contribuir com o núcleo privado.

## Uma boa sugestão de rotina

Descreva o sistema envolvido, a tarefa manual, o resultado esperado, a frequência aproximada e o que não pode ser feito automaticamente. Um exemplo fictício é suficiente para começar.

Não inclua CNPJ de cliente, documento fiscal, dados pessoais, senha, certificado, cookie, token, endereço interno ou captura de uma sessão autenticada. Não anexe logs completos de produção.

[Enviar sugestão ou pergunta técnica](https://github.com/thiagocfaria/O-ESTAGIARIO-PUBLIC/issues/new).

## Correções da documentação

Correções de clareza e links são bem-vindas. Afirmações de desempenho, cobertura ou disponibilidade precisam de fonte, contexto e revisão do mantenedor. Uma sugestão de texto não deve transformar um recurso planejado em uma capacidade anunciada.

Nenhum arquivo da documentação pública deve depender de acesso ao repositório privado para cumprir sua função. Não copie código interno, configuração de implantação ou material de terceiros sem a análise adequada.

## Questões de segurança

Não use Issues públicas para relatar detalhes sensíveis. Siga o [canal reservado em SECURITY.md](SECURITY.md). A abertura de uma discussão não concede autorização para testar portais, sistemas ou ambientes de clientes.
